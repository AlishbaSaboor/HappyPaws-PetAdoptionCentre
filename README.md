A website for a pet adoption shelter where visitors can meet adoptable pets, see adoption fees, browse pet supplies and apply to adopt. It makes finding a pet and applying for adoption simple from any device, and is built with HTML, CSS and JavaScript.

## 🚀 How to Run the Project

You can view the live project directly here: [Live Project](https://alishbasaboor.github.io/HappyPaws-PetAdoptionCentre/)

Alternatively, to run it locally:
1. Clone or download this repository.
2. Open the project folder and double-click the `index.html` file.
3. The assignment will open automatically in your default web browser.

Note: For the best experience, use a modern browser like Google Chrome or Mozilla Firefox.

## 🐾 What You Can Do on the Site

- Read about the shelter and see whether it is open right now
- Switch between light and dark mode
- Scroll through photos of life at the shelter
- Meet the adoptable pets and see more animals waiting for a home
- Check the adoption fees for dogs, cats and rabbits
- Browse pet supplies by pet type and see the total price of the items you pick
- Fill in an adoption application and get a confirmation message
- Use the site comfortably on both phone and computer
